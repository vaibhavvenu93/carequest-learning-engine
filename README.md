# CareQuest Learning Engine

Gamified learning progression system for neurodivergence care workforce training.

## Purpose

This repo explores how learners move through certification pathways using missions, XP, streaks, levels, badges, and adaptive unlocks.

## First Use Case

ABAT/RBT learner completion and exam readiness.

## Core Mechanics

- Mission-based learning
- XP accumulation
- Daily streaks
- Level progression
- Badge unlocks
- Weakness-based remediation
- Certification readiness scoring

## Long-Term Goal

Turn passive certification training into an adaptive progression system that improves completion, confidence, and job-readiness.
